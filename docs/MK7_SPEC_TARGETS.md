# Mk7 Golf spec targets

Phase 1 research, 2026-11-05: cloud web research (5 agents) plus pages/PDFs the user pasted.
**Scope (user decisions 2026-11-05):** Mk7 (2013-16) AND Mk7.5 (2017-20); GTI, GTI Performance, R; manual (MQ350) AND DSG; **5-door only; EU/UK spec only** (no NA/AU, 3-door, estate).
**Mass convention:** the user wants the CAR ONLY (no driver). Car-only = published figure minus 75 kg (see Mass basis; the subtraction is inferred, not published).

Confidence: **H** = VW primary document. **M** = ADAC / two agreeing secondary sources. **L** = single secondary, snippet, or conflicting. "no source found" = looked, nothing; never fill from memory.
Anything L or missing must be confirmed before driving a mod value. Pages still to open: bottom of this file.

## Mass basis
- ADAC "Leergewicht (EU)" is the only cell-by-cell source. EU kerb weight = ready to drive incl. 75 kg driver, 90% fuel; ADAC's page does not state it (unconfirmed on adac.de).
- **VW's own "DIN" curb weight includes driver too** (VW DE MY2020 list: driver 68 kg + luggage 7 kg + fuel). So VW press-kit numbers equal ADAC EU. Car-only = figure - 75 (inferred).
- auto-data.net offsets vs ADAC vary (45/65/75 kg): not a usable weight source.
- Consistency: Mk7 R 1476/1495 agrees between ADAC and the VW R press kit (H); Zeperfs snippet "R DSG7 1430 DIN" = 1505-75.
